# Примечания к обновлению - Система Кешбека

## Версия 2.0 - Переход на систему кешбека

### Дата выпуска
Январь 2025

### Основные изменения

#### 🎯 Новая система кешбека
- **Удалена реферальная система** полностью заменена на автоматический кешбек
- **Процент кешбека:**
  - POD-системы: 2.5%
  - Все остальные товары: 3.5%
  - Настраивается индивидуально для каждой категории

#### 💰 Начисление кешбека
- Автоматическое начисление при выполнении заказа
- Отдельный баланс кешбека (`cashback_balance`)
- Кешбек можно использовать для оплаты следующих покупок
- История всех начислений в профиле

#### 🛠 Админ панель - новые возможности

**Управление товарами (CRUD):**
```
/add_category - Добавить категорию с настройкой кешбека
/add_product - Добавить товар (название, описание, цена, количество)
/edit_product - Редактировать любое поле товара
/delete_product - Удалить товар
/products - Просмотр всех товаров
/categories - Просмотр всех категорий
```

**Управление кешбеком:**
```
/set_cashback - Настройка процента кешбека по категориям
```

**Управление заказами:**
- Кнопка "Выполнен" автоматически начисляет кешбек пользователю
- Кнопка "Не выполнен" отменяет заказ без начисления
- Уведомления пользователя о статусе заказа и начисленном кешбеке

**Главная страница:**

**Страница профиля:**

  - Всего кешбека получено

**Футер:**

#### 🗄 База данных

**Удалено:**
- Таблица `referrals`
- Поля: `referral_code`, `referred_by_id`, `is_first_purchase`

**Добавлено:**
- Таблица `cashback_transactions`:
  - id, user_id, order_id
  - amount (сумма кешбека)
  - cashback_percent (процент на момент начисления)
  - created_at
- Поле `cashback_balance` в таблице `users`
- Поле `cashback_percent` в таблице `categories`

#### 🔌 API изменения

**Новые эндпоинты:**
```
GET /users/cashback - Получить информацию о кешбеке
```

**Удаленные эндпоинты:**
```
GET /users/referral - Удален (реферальная система)
```

**Изменения в существующих:**
- `POST /users/auth` - убран параметр `referral_code`
- `GET /users/profile` - возвращает `cashback_balance` вместо `referral_code`
- `GET /users/balance` - теперь возвращает и `cashback_balance`

### Миграция

Для применения обновления:

1. **Создайте резервную копию БД:**
   ```bash
   mysqldump -u shop_user -p shop_db > backup.sql
   ```

2. **Примените миграцию:**
   ```bash
   alembic upgrade head
   ```

3. **Настройте кешбек для категорий:**
   - Войдите в админ бота
   - Используйте `/set_cashback` для каждой категории

4. **Перезапустите все сервисы:**
   ```bash
   python run_shop_bot.py &
   python run_admin_bot.py &
   python run_api.py &
   ```
