# Telegram Shop Bot + Mini App

Телеграм-бот и мини-приложение для интернет-магазина с полным функционалом корзины, оплаты, промокодов и **системой кешбека**.

## Функции

- 🛍️ **Каталог товаров** с категориями и поиском
- 🛒 **Корзина** и **избранное**
- 💰 **Промокоды** (скидка в % или рублях, пополнение баланса)
- 💳 **Система кешбека** - получайте 2.5-3.5% с каждой покупки!
- 💵 **Оплата**: СБП онлайн/при получении, наличные, баланс
- 🚚 **Доставка** (300₽) или **самовывоз** (Центр/ТЦ)
- 📦 **Управление запасами** товаров через админ-панель
- 👤 **Профиль пользователя** с балансом и кешбеком
- 🎯 **Admin Bot** с полным CRUD управлением товарами
- 🔥 **Промо-баннер** с автоматической ротацией акций

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и заполните настройки:
```bash
cp .env.example .env
```

4. Примените миграции базы данных:
```bash
alembic upgrade head
```

5. Инициализируйте категории (опционально):
```bash
python init_categories.py
```

6. Запустите бота и API:
```bash
# В одном терминале - API
python run_api.py

# Во втором терминале - Shop Bot
python run_shop_bot.py

# В третьем терминале - Admin Bot
python run_admin_bot.py
```

## Кешбек система

### Процентные ставки
- **POD-системы**: 2.5%
- **Все остальные товары**: 3.5%
- Процент настраивается индивидуально для каждой категории

### Как это работает
1. Пользователь оформляет заказ
2. Администратор получает уведомление
3. После выполнения заказа админ нажимает "Выполнен"
4. Кешбек **автоматически начисляется** на баланс пользователя
5. Пользователь может использовать кешбек для следующих покупок

## Admin Bot команды

### Управление товарами
- `/add_category` - Добавить категорию (с настройкой кешбека)
- `/add_product` - Добавить товар
- `/edit_product` - Редактировать товар
- `/delete_product` - Удалить товар
- `/products` - Список всех товаров
- `/categories` - Список категорий

### Управление кешбеком
- `/set_cashback` - Настроить процент кешбека для категории

### Управление заказами
- `/pending_orders` - Активные заказы
- При выполнении заказа автоматически начисляется кешбек

### Другое
- `/create_promo` - Создать промокод
- `/stats` - Статистика магазина

## API Endpoints

**Пользователи:**
- `POST /api/users/auth` - Авторизация
- `GET /api/users/profile` - Профиль пользователя
- `GET /api/users/cashback` - Информация о кешбеке

**Товары:**
- `GET /api/products` - Список товаров
- `GET /api/products/{id}` - Детали товара
- `GET /api/products/categories` - Категории

**Корзина:**
- `POST /api/cart/add` - Добавить в корзину
- `GET /api/cart` - Получить корзину
- `DELETE /api/cart/{product_id}` - Удалить из корзины

**Заказы:**
- `POST /api/orders` - Создать заказ
- `GET /api/orders` - История заказов

**Промокоды:**
- `POST /api/promo/validate` - Проверить промокод
- `POST /api/promo/apply-balance-promo` - Применить промокод на баланс

## Миграция с версии 1.0

Если вы обновляетесь с версии с реферальной системой:

1. **Создайте резервную копию БД!**
   ```bash
   mysqldump -u shop_user -p shop_db > backup.sql
   ```

2. **Примените миграцию:**
   ```bash
   alembic upgrade head
   ```

3. **Настройте кешбек для категорий** через админ бота (`/set_cashback`)

Подробнее см. `MIGRATION_GUIDE.md` и `UPDATE_NOTES.md`
