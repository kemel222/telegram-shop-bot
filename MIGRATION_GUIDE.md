# Руководство по миграции с реферальной системы на кешбек

## Обзор изменений

Этот проект был обновлен с системы рефералов на систему кешбека со следующими основными изменениями:

### 1. База данных

**Удалено:**
- Таблица `referrals`
- Колонки в `users`: `referral_code`, `referred_by_id`, `is_first_purchase`

**Добавлено:**
- Таблица `cashback_transactions` для отслеживания начислений кешбека
- Колонка `cashback_balance` в таблице `users`
- Колонка `cashback_percent` в таблице `categories` (по умолчанию 3.5%)

### 2. Система кешбека

**Процентные ставки:**
- POD-системы: 2.5%
- Все остальные товары: 3.5%
- Настраивается для каждой категории индивидуально

**Начисление:**
- Кешбек начисляется автоматически при завершении заказа (статус `COMPLETED`)
- Начисляется на `cashback_balance` и `balance` пользователя
- История хранится в таблице `cashback_transactions`

### 3. Администраторская панель

**Новые команды:**

**Управление товарами:**
- `/add_category` - Добавить категорию (с настройкой кешбека)
- `/add_product` - Добавить товар
- `/edit_product` - Редактировать товар
- `/delete_product` - Удалить товар
- `/products` - Список товаров
- `/categories` - Список категорий

**Управление кешбеком:**
- `/set_cashback` - Настроить процент кешбека для категории

**Управление заказами:**
- При выполнении заказа (кнопка "Выполнен") автоматически начисляется кешбек

### 4. API изменения

**Удалено:**
- `GET /users/referral` - информация о рефералах

**Добавлено:**
- `GET /users/cashback` - информация о кешбеке пользователя

**Изменено:**
- `POST /users/auth` - больше не принимает `referral_code`
- `GET /users/profile` - возвращает `cashback_balance` вместо `referral_code`

### 5. Telegram Bot изменения

**Shop Bot:**
- Удалена команда "🎁 Реферальная программа"
- Добавлена команда "💰 Кешбек"
- В профиле отображается кешбек баланс
- В приветственном сообщении информация о кешбеке

**Admin Bot:**
- Добавлено полное CRUD управление товарами
- Добавлена настройка кешбека по категориям
- При завершении заказа автоматически начисляется кешбек

### 6. Web приложение

**Изменения:**
- Страница Profile: удалена информация о рефералах, добавлена информация о кешбеке
- Главная страница: добавлен баннер с акциями (обновляется каждые 15 сек)
- Добавлено упоминание разработчика @x32asm

## Как применить миграцию

### 1. Резервное копирование

```bash
# Создайте резервную копию базы данных
mysqldump -u shop_user -p shop_db > backup_before_migration.sql
```

### 2. Применение миграции

```bash
# Применить миграцию
alembic upgrade head
```

### 3. Проверка

```bash
# Проверить, что все таблицы созданы правильно
mysql -u shop_user -p shop_db

# В MySQL консоли:
SHOW TABLES;
DESCRIBE users;
DESCRIBE categories;
DESCRIBE cashback_transactions;
```

## Настройка после миграции

### 1. Настройка процентов кешбека для категорий

Войдите в админ бота и используйте команду `/set_cashback` для настройки процента кешбека для каждой категории.

Рекомендуемые значения:
- POD-системы: 2.5%
- Жидкости: 3.5%
- Одноразки: 3.5%
- Картриджи: 3.5%

### 2. Обновление переменных окружения

Убедитесь, что в `.env` файле есть:

```env
CASHBACK_PODS_PERCENT=2.5
CASHBACK_DEFAULT_PERCENT=3.5
DEVELOPER_USERNAME=x32asm
DEVELOPER_LINK=https://t.me/x32asm
```

### 3. Перезапуск сервисов

```bash
# Перезапустить все сервисы
# Shop bot
python run_shop_bot.py

# Admin bot
python run_admin_bot.py

# API
python run_api.py

# WebApp (если используется)
cd webapp
npm start
```

## Откат миграции

Если что-то пошло не так, вы можете откатить изменения:

```bash
# Откатить миграцию
alembic downgrade -1

# Или восстановить из резервной копии
mysql -u shop_user -p shop_db < backup_before_migration.sql
```

## Часто задаваемые вопросы

**Q: Что происходит со старыми данными рефералов?**
A: Данные о рефералах удаляются при миграции. Если вы хотите сохранить историю, создайте резервную копию перед миграцией.

**Q: Можно ли изменить проценты кешбека?**
A: Да, администратор может изменить процент кешбека для каждой категории через команду `/set_cashback` в админ боте.

**Q: Кешбек начисляется автоматически?**
A: Да, кешбек начисляется автоматически когда администратор помечает заказ как "Выполнен".

**Q: Можно ли откатить миграцию?**
A: Да, используйте команду `alembic downgrade -1` или восстановите из резервной копии.
